تکنیک های کاهش سریع اضطراب : 1- یک دم و بازدم عمیق، فقط همین

🔹تکنیک های کاهش سریع اضطراب : 1- یک دم و بازدم عمیق، فقط همین. حتی اگه فقط یه نفس عمیق و آهسته بکشی،سیگنال "فعلاً امنیت نسبی" به مغزت میره. 2- اسم حس‌ات رو بگو. همون لحظه، فقط با خودت بگو “می‌ترسم” یا “نگرانم”.(اسم‌گذاری احساس، قدرتش رو کم می‌کنه.) 3- یه جسم سرد رو لمس کن. دستت رو ببر روی شیشه، فلز یا یه بسته سرد دم دست. 4- به خودت بگو: "من الان اینجام." یعنی فقط این جمله رو زیر لب بگو.این جمله مغز رو از فضای شوک بیرون میاره. 5- یه پیام ساده بده یا یه نفر رو صدا بزن. هرنوع ارتباط فوری(حتی ارسال یک ایموجی به دوستت)سریع مدار آرامش اجتماعی رو فعال می‌کنه. فقط یکی از این کارا رو انجام بدی، مغزت توی چند ثانیه کمی آرومتر میشه.خودت رو مجبور نکن همه‌ش رو انجام بدی؛ یکی هم کافیه. #متن 🔹@mahoonartmagazine
